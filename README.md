# Society Maintenance Management System — PHP + Node.js + MySQL

This project was adapted from the uploaded `1.zip` project. The existing visual styling and browser JavaScript were retained, and the application backend was rebuilt around PHP and Node.js with MySQL as the shared persistent database. The original Flask/SQLite source is kept in `legacy-python-original/` as a reference only; it is not needed to run the new application.

## Technology stack

- **Frontend:** HTML generated by PHP, Bootstrap 5, retained CSS and JavaScript
- **PHP backend:** login/session security, flats, residents, bills, payment recording, complaints, notices, expenses and reports
- **Node.js backend:** Express REST API for complaint tracking and status updates
- **Database:** MySQL / MariaDB

PHP and Node.js connect independently to the same MySQL database. PHP serves the browser UI; the Node API is a separate service for API-based complaint integrations. The internal API key is server-side only and must never be placed in browser JavaScript.

## Features implemented

- Role-based admin/resident login with password hashing
- Admin dashboard with live MySQL totals
- Flat listing and flat creation
- Resident account creation linked to a vacant flat
- Monthly bills generated for occupied flats without duplicate flat/month bills
- Resident-only bill visibility and demo payment recording with receipt numbers
- Payment ledger
- Resident complaint submission; admin complaint status/remarks updates
- Notices and expense records
- Basic financial and complaint reports
- CSRF tokens, prepared SQL statements, session cookie protections, and role checks
- Node.js health endpoint and protected complaint list/update REST endpoints

**Payment note:** The payment action is a demo/admin-recorded payment workflow. It does not charge a bank account or process real UPI/card transactions.

## Requirements

- XAMPP (Apache + MySQL/MariaDB) or equivalent
- PHP 8.1+ with `pdo_mysql` enabled
- Node.js 18+
- VS Code (optional)

## Installation on Windows (XAMPP + VS Code)

1. Extract the ZIP file.
2. Copy the `society_maintenance_management` folder into `C:\xampp\htdocs\`.
3. Start **Apache** and **MySQL** in the XAMPP Control Panel.
4. Open `http://localhost/phpmyadmin`.
5. Create/import the database by opening the **Import** tab and selecting `database/society_management.sql`. The SQL creates the `society_management` database and its tables.
6. Check `php/config/database.php`. The defaults match a typical local XAMPP installation (`127.0.0.1`, port `3306`, user `root`, empty password). If your MySQL account differs, set the `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, and `DB_PASSWORD` environment variables or update the local-only configuration.
7. Open a terminal in the project folder and run:
   ```powershell
   php php/setup_demo.php
   ```
   This creates demo accounts, flats, resident profiles, and a sample notice. Run it after importing the schema. It is safe to re-run for the provided seed records.
8. Open the app at `http://localhost/society_maintenance_management/php/public/`.

## Start the Node.js backend

1. Copy `node-backend/.env.example` to `node-backend/.env`.
2. Set `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, and `DB_PASSWORD` to the same MySQL database used by PHP.
3. Set `INTERNAL_API_KEY` to a long random secret. Do not commit the `.env` file.
4. Open a terminal:
   ```powershell
   cd node-backend
   npm install
   npm start
   ```
5. Health check: `http://localhost:3001/api/health`.

### Node.js API endpoints

Protected endpoints require `Authorization: Bearer YOUR_INTERNAL_API_KEY` and JSON requests where applicable.

- `GET /api/health` — verifies the Node service and MySQL connection.
- `GET /api/complaints` — returns complaint tracking data.
- `PATCH /api/complaints/:id/status` — updates status, admin remarks, and optional staff assignment.

Example status update:
```powershell
curl -X PATCH http://localhost:3001/api/complaints/1/status `
  -H "Authorization: Bearer YOUR_INTERNAL_API_KEY" `
  -H "Content-Type: application/json" `
  -d '{"status":"In Progress","admin_remarks":"Technician assigned"}'
```

The API key is intended for trusted server-to-server use. Do not embed it in `static/js` or any other browser-delivered file. For a public deployment, replace the shared internal-key pattern with user authentication and role-based authorization for each API request.

## Troubleshooting

- **Database connection error:** verify MySQL is running, database `society_management` exists, and PHP's `pdo_mysql` extension is enabled.
- **Unknown database/table:** import `database/society_management.sql` before running setup.
- **Login doesn't work:** run `php php/setup_demo.php` after importing the schema.
- **Node API returns 401:** check the `Authorization` bearer token and `INTERNAL_API_KEY` in `node-backend/.env`.
- **Port already in use:** change `PORT` in `node-backend/.env`.
- **PHP pages show raw code or download:** use Apache/XAMPP or PHP's development server; do not open PHP files directly with `file://`.
